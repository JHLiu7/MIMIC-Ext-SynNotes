# MIMIC-Ext-SynNotes

This repository accompanies the paper:

**Systematic Evaluation of the Quality of Synthetic Clinical Notes Rephrased by LLMs at Million-Note Scale**
Jinghui Liu, Sarvesh Soni, Anthony Nguyen.

## Dataset Access

The synthetic clinical note corpus (**MIMIC-Ext-SynNotes**) is currently under review for release on PhysioNet. The official access link will be posted here once approved.

**Status:** Under review on PhysioNet.

Because the corpus is derived from MIMIC-III and MIMIC-IV, access will require PhysioNet credentialing and acceptance of the relevant data use agreements.
